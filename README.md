# Nido Village

Σύστημα παραγγελιοληψίας, PDA, ταμείου και αποθήκης για κατάστημα εστίασης, με νόμιμη έκδοση παραστατικών μέσω πιστοποιημένου παρόχου ΥΠΑΗΕΣ (ΑΑΔΕ myDATA) και διασύνδεση POS.

**Κατάσταση:** σχεδιασμός. Δεν υπάρχει ακόμη κώδικας.

- [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md): νομικό πλαίσιο, αρχιτεκτονική, εκτυπωτές, ροή προς εφορία, φάσεις, κόστη, ρίσκα, επόμενα βήματα.
